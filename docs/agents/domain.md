# Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Resolve these paths from this repository's root.

Before domain-related exploration, read the glossary and relevant ADRs.
For cross-repository work, also read the affected repositories' domain docs.

If these documents do not exist, proceed without creating placeholders.
Use glossary terms consistently. Surface conflicts with existing ADRs
before proposing a different decision.
